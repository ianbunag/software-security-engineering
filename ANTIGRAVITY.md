# Antigravity Slash Commands

| Command | Category | Description |
| :--- | :--- | :--- |
| `/plan` | Planning & Task Guidance | Formulate a detailed implementation plan before making code changes. |
| `/grill-me` | Planning & Task Guidance | Conduct an interactive interview to align on design decisions and requirements. |
| `/btw` | Planning & Task Guidance | Send a quick side note without altering the current task context. |
| `/context` | Context & Artifacts | View or manage current context and loaded files. |
| `/artifact` | Context & Artifacts | View and manage generated artifacts. |
| `/clear` | Session Management | Clear the current conversation history. |
| `/resume` | Session Management | Resume a previous conversation session. |
| `/exit` | Session Management | Exit the Antigravity session. |
| `/model` | Configuration & Metrics | Select or switch the active AI model. |
| `/config` | Configuration & Metrics | View or adjust configuration settings. |
| `/usage` | Configuration & Metrics | Display token usage and session limits. |
